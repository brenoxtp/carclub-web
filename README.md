# Car Club Centro Automotivo — Landing Page

Landing page estática e responsiva para apresentar a Car Club de Três Pontas–MG e direcionar pedidos de avaliação/orçamento ao WhatsApp. Projeto demonstrativo independente, ainda não aprovado oficialmente pela oficina.

## Como rodar
Abra `index.html` em um navegador ou rode `python -m http.server 8000` na pasta do projeto. Acesse http://localhost:8000. Não é necessário npm, build, banco de dados ou API.

## Arquivos
- `index.html` — conteúdo e marcação semântica
- `styles.css` — identidade visual e estilos responsivos
- `script.js` — menu mobile e tratamento de imagens
- `assets/favicon.svg` — ícone ilustrativo
- `recon/fontes-e-imagens.md` — fontes e pendências de uso de imagens

## Funcionalidades
Menu responsivo, FAQ acessível, Google Maps, CTAs para WhatsApp com mensagens contextuais, layout mobile-first, SEO básico, dados estruturados e fallback de imagens externas.

## Antes de publicar comercialmente
Validar autorização das fotografias e da marca, substituir links externos por imagens licenciadas hospedadas no projeto, conferir telefone, endereço, serviços e mapa e verificar as fotos da galeria. Não são apresentados testemunhos nem resultados de serviços não comprovados. Consultar `recon/fontes-e-imagens.md`.

## Hospedagem
Pode ser publicado em GitHub Pages, Netlify ou Vercel como site estático. A simples publicação deste repositório no GitHub não ativa automaticamente um site público.
